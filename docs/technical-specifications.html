3. ISO 8573-1 Air Quality Standards

The ISO 8573-1 standard defines air quality classes based on three key contaminants: Particles, Moisture (dew point), and Oil.

3.1 Air Quality Classes

Class Max Particle Size Max Moisture Max Oil Content
Class 0 0.1 μm -40°C dew point 0.003 mg/m³
Class 1 1 μm -40°C dew point 0.01 mg/m³
Class 2 1 μm -20°C dew point 0.1 mg/m³
Class 3 5 μm -20°C dew point 0.1 mg/m³
Class 4 5 μm +3°C dew point 1 mg/m³
Class 5 40 μm +7°C dew point 1 mg/m³
Class 6 40 μm +7°C dew point 5 mg/m³

3.2 Class Selection Guide

  • Class 0 — Aerospace, pharmaceutical, medical gas, food processing
  • Class 1-2 — Medical equipment, electronics, precision instruments
  • Class 3-4 — Pneumatic tools, painting, packaging machinery
  • Class 5-6 — Non-critical applications, basic tooling

6. Complete Treatment Paths

Path 1: High-Purity System (Class 0-1)

Configuration: Compressor → Storage Tank → G-Filter → C-Filter → Refrigerated Dryer → D-Filter → S-Filter → Desiccant Dryer

Applications: Pharmaceutical, Medical gas, Food processing, Electronics

Path 2: Standard Industrial (Class 3-4)

Configuration: Compressor → Storage Tank → G-Filter → C-Filter → Refrigerated Dryer

Applications: Pneumatic tools, General painting, Packaging machinery

Path 3: Precision Industrial (Class 1-2)

Configuration: Compressor → Storage Tank → G-Filter → C-Filter → Blower Dryer → D-Filter

Applications: Precision instruments, Medical equipment, Laboratory use

Path 4: General Purpose (Class 5-6)

Configuration: Compressor → Storage Tank → G-Filter

Applications: Simple tooling, Non-critical ventilation, Basic industrial use
