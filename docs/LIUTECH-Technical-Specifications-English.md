## 4. ISO 8573-1 Air Quality Standards

The International Organization for Standardization (ISO) 8573-1 standard defines air quality classes based on three key contaminants:

### 4.1 Contaminant Types

| Contaminant | Description | Unit |
|------------|------------|------|
| **Particles** | Solid particles of varying size | μm (micron) |
| **Moisture** | Water content (dew point) | °C |
| **Oil** | Total oil including vapor | mg/m³ |

### 4.2 Air Quality Classes

| Class | Max Particle Size | Max Moisture | Max Oil Content |
|-------|---------------|------------|-------------|
| **Class 0** | 0.1 μm | -40°C dew point | 0.003 mg/m³ |
| **Class 1** | 1 μm | -40°C dew point | 0.01 mg/m³ |
| **Class 2** | 1 μm | -20°C dew point | 0.1 mg/m³ |
| **Class 3** | 5 μm | -20°C dew point | 0.1 mg/m³ |
| **Class 4** | 5 μm | +3°C dew point | 1 mg/m³ |
| **Class 5** | 40 μm | +7°C dew point | 1 mg/m³ |
| **Class 6** | 40 μm | +7°C dew point | 5 mg/m³ |

### 4.3 Class Selection Guide

**Class 0 (Highest Purity)**
- Aerospace manufacturing
- Pharmaceutical production
- Medical gas preparation
- Food grade air

**Class 1-2 (High Purity)**
- Medical equipment
- Electronics manufacturing
- Precision instruments
- Laboratory applications

**Class 3-4 (Standard Industrial)**
- Pneumatic tools
- General painting
- Packaging machinery
- Industrial automation

**Class 5-6 (Basic)**
- Non-critical applications
- General ventilation
- Simple tooling

## 5. Air Treatment System Configuration

### 5.1 System Overview

The LIUTECH air treatment system provides a complete solution from compression to point-of-use, featuring:

1. **Central Compressor** - Generates compressed air
2. **Storage Tank** - Stabilizes pressure and stores air reserves
3. **Treatment Path** - Removes contaminants to meet target purity class
4. **Distribution** - Delivers to individual applications

### 5.2 Filter Series

LIUTECH offers multiple filter series for specific applications:

| Filter | Type | Application |
|--------|------|------------|
| **G-Series** | General Purpose | Pre-filtration, removing large particles |
| **C-Series** | Coalescing | Removing oil aerosols and fine particles |
| **D-Series** | Desiccant | Adsorption drying, removing moisture |
| **V-Series** | Vacuum | Vacuum dryer systems |
| **S-Series** | Sterile | Sterile/medical grade filtration |

### 5.3 Dryer Types

**Refrigerated Dryers**
- Cooling method: Refrigerant-based
- Dew point: +3°C to +7°C
- Ideal for: Class 4-5 applications
- Low maintenance requirements

**Blower Suction Dryers**
- Cooling method: Ambient air blown through heat exchanger
- Dew point: -20°C to -40°C
- Ideal for: Class 1-3 applications
- Energy-efficient option

**Desiccant Dryers**
- Drying method: Desiccant material absorption
- Dew point: -40°C and below
- Ideal for: Class 0-1 applications
- Regeneration cycle required
