# LIUTECH Air Compressor Website

## 1. Concept & Vision

A professional B2B showcase website for LIUTECH industrial air compressors. Bold, industrial, and trustworthy — like premium factory equipment catalog meets modern tech startup. Clean and engineering-sharp, showcasing the LU250 PM+ dual-motor drive system and ISO 8573-1 air quality solutions.

## 2. Design Language

**Aesthetic:** Industrial engineering — deep navy blues, clean whites, electric cyan accents. Bold geometric shapes suggesting hydraulic precision.

**Colors:**
- Primary: `#0A1628` (deep navy — authority)
- Secondary: `#1C3A5E` (steel blue — industrial)
- Accent: `#00D4FF` (electric cyan — energy/air)
- Background: `#F4F7FA` (clean light grey)
- Dark bg sections: `#0A1628`
- Text primary: `#0A1628`
- Text light: `#FFFFFF`

**Typography:**
- Headings: 'Rajdhani', sans-serif (geometric, industrial)
- Body: 'Inter', sans-serif (clean readability)

**Motion:**
- Scroll-triggered fade-up animations
- Subtle hover lifts on cards
- Cyan glow pulse on CTA buttons

**Icons:** Lucide icons via CDN

## 3. Layout & Structure

Single-page scrolling site:
1. **Hero** — Dark section with LU250 PM+ headline, tagline, compressor image
2. **Key Features** — 4 feature cards highlighting dual motor drive, energy efficiency, ISO standards, industrial build
3. **Product Images Gallery** — 6 images of the actual LIUTECH compressor and system
4. **ISO Air Quality System** — Explained in English with filter configurations
5. **Product Configurations** — Four treatment paths with G/C/D/V/S filters and dryers
6. **Contact** — Phone number prominently displayed
7. **Footer** — Brand info

## 4. Features & Interactions

- Smooth scroll navigation
- Image gallery with hover effects
- Product cards with hover lift + cyan border
- "Call Now" triggers tel: link
- Responsive: mobile-first, stacks on small screens

## 5. Technical Approach

- Pure HTML5 + CSS3 + Vanilla JS
- Google Fonts (Rajdhani + Inter)
- Lucide icons via CDN
- Images stored in local /images folder
- No build tools — deploy to GitHub Pages
